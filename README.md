# LOL 个签管理器

国服《英雄联盟》个性签名管理工具 —— 轻量化、单文件、免安装。保存多条个签随时切换，还能根据**时间、天气、最近一局战绩**自动生成个性签名，可选接入 AI 让文案不重样。

> 非官方第三方工具，与拳头游戏（Riot Games）/腾讯游戏无任何关联。《英雄联盟》《League of Legends》为 Riot Games, Inc. 的注册商标。

## 项目起源

最早是看到一个叫 Awesome ABC 的作品，试用后觉得思路不错，但个签每次重启客户端都会自己改回来，频繁使用就要反复重新输入指令和内容，比较麻烦。后来从[贴吧一位网友的帖子](https://tieba.baidu.com/p/9035884910?see_lz=1)里学到了修改思路，对方封装的方案要 75MB，于是我用 PowerShell + txt + bat 写了个 2KB 的绿色版本先丢了出来。

后来发现类似的小工具居然有人在卖钱，就干脆把它做成一个正经的、带界面的完整工具，继续免费分享给大家——也就是现在这个版本：从命令行脚本升级成了带 GUI 的单文件 exe，加上了时间/天气/战绩灵感、AI 生成、自动检测这些功能。

## 这是什么

打完一把想换个签，但不知道写什么？这个工具能帮你：

- **保存多条个签**，列表里随时点选切换
- **🕐 时间灵感**：根据当前时段（凌晨/早上/中午/下午/晚上）随机生成一句，热血、emo、可爱、嚣张、chill、阴阳怪气六种风格随机切换
- **🌤 天气灵感**：结合当地天气生成应景文案
- **🎮 战绩灵感**：读取你最近一局的英雄、KDA、多杀、伤害、连杀等数据，生成贴合这把战绩的个签——赢了就痛快，输了就卖萌卖惨，绝不写车轱辘话
- **🔁 自动模式**：打完一局，自动检测并把个签换成这把的战绩感想，全程不用管
- **😀 表情面板**：中/日式颜文字 + 常用 emoji，点一下插入
- **⚙ AI 智能生成（可选）**：接入智谱 GLM（免费）/ DeepSeek / Claude，让 AI 现场写，每次风格不重复；没配置也完全不影响使用，会自动退回本地模板

自动区分「经典排位/匹配」和「海克斯大乱斗」等其他模式，不会把「峡谷」「上分」「大龙」这些排位专属词乱用到大乱斗里。

## 下载 & 使用

1. 从 [Releases](../../releases) 下载 `LOL个签管理器.exe`
2. 双击运行，弹出 UAC 提示时点击「是」（见下方「为什么要管理员权限」）
3. 开着 LOL 客户端，点对应的灵感按钮，或直接编辑个签后点「应用到客户端」

不需要安装任何运行环境，Windows 10/11 自带的组件即可运行。

## AI 功能怎么开启（可选）

不开也能正常用（走本地模板）。想要 AI 现场生成、每次都不一样，可以：

1. 打开软件里的「⚙ AI 智能生成」折叠面板
2. 服务选 **智谱 GLM-4-Flash（免费）**——去 [bigmodel.cn](https://bigmodel.cn) 注册，控制台创建 API Key，粘贴进去
3. 点「测试」，显示「已连通 ✅」就好了

也支持 DeepSeek（低价按量付费）和 Claude（需要能连上 `api.anthropic.com` 的网络环境 + 付费 API Key）。Key 只保存在本地的 `ai_config.json`，不会上传到任何地方（除了直接请求你选的 AI 服务商官方接口）。

## ⚠️ 关于杀毒软件误报（重要）

**下载后被 Windows/杀毒软件直接删除、提示"发现病毒"，是已知的误报，不代表软件有问题。**

**为什么会这样：** 这个工具用 [ps2exe](https://github.com/MScholtes/PS2EXE) 把 PowerShell 脚本打包成了 exe。为了正常工作，它需要请求管理员权限、读取 LOL 客户端进程的命令行信息（用来提取本地认证 token）、发起网络请求——这几个行为凑在一起，跟"窃取凭据的木马"的行为模式非常像，很容易被杀毒软件的启发式引擎直接误判为病毒并静默删除。**源码完全公开**（`LolSignatureManager.ps1`），欢迎自行审查，这是判断软件是否安全最可靠的方式。

**如果文件被删了：**

1. **从隔离区恢复**：Windows 安全中心 → 病毒和威胁防护 → 保护历史记录，找到被删的文件，选"允许在设备上运行"或"还原"
2. **下载前先排除**：Windows 安全中心 → 病毒和威胁防护设置 → 管理设置 → 排除项 → 把你打算存放 exe 的文件夹加进去，再重新下载就不会被自动删
3. **核对文件完整性**：每个 [Release](../../releases) 都会在发布说明里给出 SHA256 校验值，下载后可以在 PowerShell 里核对是否一致：
   ```powershell
   Get-FileHash "LOL个签管理器.exe" -Algorithm SHA256
   ```
4. **最保险的方式：直接跑源码，不用 exe**。下载 `LolSignatureManager.ps1`，自己看一遍代码，用管理员 PowerShell 运行（见下方"从源码运行"），完全绕开杀毒软件对编译后二进制文件的误报，也是最透明的用法
5. **想帮大家一起减少误报**：可以把 exe 提交到 [微软文件误报复核页面](https://www.microsoft.com/en-us/wdsi/filesubmission)，积累的反馈多了，Defender 云端库会逐渐放行，帮到后面所有下载的人

## 常见问题

**会不会被封号？**
不会。本工具用的是 LOL 客户端自带的本地接口（League Client Update，LCU），和 OP.GG 桌面版、掌盟这类第三方战绩工具原理完全一样——只读取你自己的战绩数据、修改你自己的状态文本，不涉及任何自动操作、外挂或数据篡改，也不连接游戏服务器。

**为什么要管理员权限？**
读取 LOL 客户端进程信息（用来拿到本地认证 token）需要管理员权限，这是 Windows 系统层面的限制，软件本身不会做任何需要额外权限的危险操作。

**天气获取失败怎么办？**
国内天气源需要在「城市」栏填写中文城市名（如：上海、成都）。如果还是失败，弹窗会显示具体失败原因，欢迎带着这个信息来提 Issue。

**数据存在哪里？**
个签列表存在软件同目录的 `signatures.json`，AI 配置存在 `ai_config.json`，都是纯本地文件，删掉软件文件夹就是彻底清除，不会上传到任何服务器。

**AI 生成的内容感觉不太对怎么办？**
提 Issue 告诉我具体场景（时间/天气/战绩）和不满意的地方，欢迎反馈。

## 从源码运行 / 自行编译

依赖 [ps2exe](https://github.com/MScholtes/PS2EXE) 模块：

```powershell
Install-Module ps2exe -Scope CurrentUser

Invoke-ps2exe -inputFile LolSignatureManager.ps1 -outputFile "LOL个签管理器.exe" `
    -iconFile app.ico -noConsole -requireAdmin -x64 -STA `
    -title 'LOL个签管理器' -product 'LOL个签管理器'
```

或者不打包，直接用管理员 PowerShell 运行：

```powershell
powershell -ExecutionPolicy Bypass -File LolSignatureManager.ps1
```

## 技术细节

- PowerShell + WPF，单文件 exe（约 130KB），无控制台窗口
- 通过 LCU 本地 API（`https://127.0.0.1:<port>`）读取召唤师信息、战绩、修改状态消息
- 战绩相关数据：英雄、KDA、多杀、连杀、伤害、出装、对局模式等
- 天气：国内免 key 源，多源兜底
- 自动模式：监听客户端对局阶段（gameflow-phase），离开对局后轮询检测新战绩，避免频繁访问战绩接口导致客户端自身「近期对局」面板异常
